Installation in three steps

1

Download and run

Click Install for Windows, then open Prompt2Print-Setup-1.1.0.msi from your Downloads folder. If Windows shows “Windows protected your PC”, click More info → Run anyway (the installer is not code-signed yet). The app goes to C:\Program Files\Prompt2Print with a desktop shortcut.

2

First start

Open Prompt2Print from the desktop. The first start takes about 30 seconds while the catalog and product photos are created. Come back to this page: it detects the app and shows the next step.

3

Set up the shop

In the app, open Settings and add your Tap Payments key, a Meshy or Tripo key for AI models, and your Bambu Lab P2S printer (IP, serial number, LAN access code, AMS slots). Then the shop is ready for customers.

What is inside

  • Shop with catalog, cart, accounts, orders and tracking, English and Arabic (RTL), mobile friendly
  • AI Create: prompt → 3D model you can rotate, resize and price before buying (Meshy/Tripo, with a built-in generator as fallback)
  • Live pricing: item price, tax and shipping by country, service fee, shown in the customer's currency
  • Automatic printing after payment on a Bambu Lab P2S Combo: slice → queue → print → status updates
  • Admin panel: orders, products, materials and colours in stock, printers, pricing, taxes, shipping, reports, security log
  • Complete source code installed with the app (…\Prompt2Print\app)

Requirements

  • Windows 10 or 11, 64-bit. Microsoft Edge (included in Windows) for the app window.
  • No other installs: the Node.js runtime is inside the installer. Your data stays in %LOCALAPPDATA%\Prompt2Print and survives updates.
  • For real orders: a Tap Payments account (cards from anywhere in the world). For AI models: a Meshy or Tripo key with credits.
  • Printer: Bambu Lab P2S Combo on the same network, LAN mode with developer mode on.
Not for food or drink. Printed items are not food-safe. Do not microwave, bake, or dishwash. Heat-resistant up to ~85°C (ABS) / ~100°C (ASA). Keep away from open flame.

Questions

SmartScreen warns about any installer that is not signed with a paid code-signing certificate. The installer is built from the public source in this repository; its SHA-256 is published next to it. Click “More info → Run anyway”.

Start Prompt2Print from the desktop shortcut and wait for its window to open, then press “Check again”. The page can only see the app on the same computer. Some browsers ask for permission to reach a local app; allow it.

Run a newer installer over the old one; your shop data is kept. Uninstall from Windows Settings → Apps; the data folder is left in place.
