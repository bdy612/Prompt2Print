Prompt2Print

Describe it. We print it and ship it.

A marketplace for 3D-printed products with AI Create: type what you want, see it in 3D, price it instantly, and it is printed to order after payment. English and Arabic.

Download for Windows (.msi)
Version 1.1.0 · Windows 10/11 64-bit · one file, nothing else to install · all releases

1. Install

Double-click the .msi. Windows may show “Windows protected your PC”: click More info → Run anyway (the installer is not code-signed yet).

2. Open

Start Prompt2Print from the desktop or Start menu. The first start takes about 30 seconds while the catalog is created.

3. Set up

Sign in as the admin, then under Settings add your Tap Payments key, your Meshy/Tripo key for AI models, and your Bambu Lab P2S printer.

Not for food or drink. Printed items are not food-safe. Do not microwave, bake, or dishwash. Heat-resistant up to ~85°C (ABS) / ~100°C (ASA). Keep away from open flame.
Source code: github.com/bdy612/Prompt2Print · The installer also contains the complete source in C:\Program Files\Prompt2Print\app.
